# Tank Warz

Tank Warz is an original top-down browser tank arena built with React and the Canvas 2D API. One pilot and AI-controlled squads battle across the large Rustfall Basin map in 1v1, 2v2, or 3v3 team deathmatches.

## Play

- `WASD` or arrow keys — move
- Mouse — aim
- Click or `Space` — fire
- `E` — class ability
- `Esc` — pause

Touch controls appear automatically on coarse-pointer landscape devices.

## Tanks

- **Jackal** — fast flanker with Rocket Skid
- **Mammoth** — armored vanguard with Bulwark Field
- **Longshot** — siege controller with Meteor Mortar

## Local development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Use `npm test` for the production build and rendered smoke tests, or `npm run lint` for static checks.
